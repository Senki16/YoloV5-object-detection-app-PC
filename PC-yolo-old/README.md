# Detector de Objetos Sheik 🛡️

¡El mejor de todo Hyrule!

Aplicación de detección de objetos en tiempo real utilizando YOLOv5 y la cámara web.

## 🚀 Cómo ejecutar la app

1. Asegúrate de tener instaladas las dependencias necesarias. Si aún no las has instalado, ejecuta:
   ```bash
   pip install -r requirements.txt
   ```

2. Inicia la aplicación ejecutando el script principal:
   ```bash
   python webcam_app.py
   ```

3. La aplicación abrirá una ventana que mostrará la cámara web y detectará los objetos en tiempo real.
4. Para cerrar la aplicación en cualquier momento, presiona la tecla `ESC` en tu teclado.
